# Dra. Dayane Rodrigues — Tia Day | Landing Page

Landing page premium da odontopediatra **Dra. Dayane Rodrigues (Tia Day)**, em Belo Horizonte/MG.

Página única, responsiva (mobile-first), focada em conversão via WhatsApp, com foco em acolhimento, tecnologia e prevenção da saúde bucal infantil.

## Stack
- HTML + CSS + JavaScript puro (sem build, sem dependências)
- Google Fonts (Montserrat + Quicksand/Caviar Dreams)
- Schema.org (`Dentist` + `FAQPage`) para SEO local
- Animações em scroll (IntersectionObserver), carrossel de depoimentos, FAQ acordeão, contadores animados

## Estrutura
- `index.html` — página completa
- `assets/` — logos e fotografias

## Como rodar
Basta abrir o `index.html` no navegador. Para publicar, qualquer hospedagem estática serve (GitHub Pages, Netlify, Vercel).

## Configuração rápida
No fim do `index.html`, em `CONFIG`, ajuste o número de WhatsApp e a mensagem padrão.
